## Jawaban
Untuk event delegation itu adalah teknik di JavaScript yang digunakan supaya kita tidak perlu memasang event listener pada setiap elemen satu per satu. Jadi cukup memasang satu event listener pada elemen parent saja, setelah itu event dari elemen anak akan diteruskan ke parent melalui proses yang disebut event bubbling.

Misalnya kita punya banyak tombol hapus di dalam sebuah tabel. Kalau setiap tombol diberi event listener sendiri, jumlah event listener akan semakin banyak dan kode jadi lebih panjang. Nah dengan event delegation kita cukup memasang event listener pada tabel atau pembungkusnya, lalu saat salah satu tombol diklik sistem akan mengecek tombol mana yang sebenarnya ditekan.

Contohnya seperti ini:

```
javascript id="fqukk8"
document.getElementById("daftar").addEventListener("click", function(e) {
    if (e.target.classList.contains("hapus")) {
        console.log("Tombol hapus diklik");
    }
});
```

Nah pada kode di atas event listener dipasang pada elemen yang memiliki id "daftar". Setelah itu ketika pengguna mengklik tombol yang memiliki class "hapus", event tersebut akan naik ke parent. Lanjut sistem akan mengecek apakah elemen yang diklik memang memiliki class "hapus" atau tidak. Kalau iya maka perintah yang ada di dalamnya akan dijalankan.

Keuntungan menggunakan event delegation itu cukup banyak. Pertama kita tidak perlu membuat banyak event listener sehingga penggunaan memori jadi lebih hemat. Setelah itu kode juga jadi lebih rapi dan lebih mudah dibaca. Lanjut kalau nanti ada elemen baru yang ditambahkan secara otomatis menggunakan JavaScript, kita tidak perlu menambahkan event listener lagi karena parent sudah menangani semua event dari elemen anaknya.

Jadi menurut saya event delegation adalah cara yang lebih efisien untuk menangani event pada banyak elemen sekaligus. Daripada memasang event listener satu per satu, kita cukup memasangnya pada parent lalu membiarkan event dari child diteruskan ke parent. Dengan begitu kode menjadi lebih sederhana, lebih mudah dikelola, dan lebih cocok digunakan pada aplikasi web yang memiliki banyak elemen yang bisa berubah secara dinamis.
