Refaktorisasi

```
function fetchOrderDetails(orderId, token) {
    fetch(`https://example.com/api/order/${orderId}`, {
        headers: {
            Authorization: token
        }
    })
        .then(validateResponse)
        .then(response => response.json())
        .then(order => {
            displayOrderModal(order);
            setupCloseButton();
            setupConfirmButton(order, token);
        })
        .catch(handleError);
}

function validateResponse(response) {
    if (!response.ok) {
        throw new Error("Failed to fetch order details");
    }

    return response;
}

function displayOrderModal(order) {
    const modal = document.getElementById("orderModal");
    const orderDetails = modal.querySelector("#orderDetails");

    orderDetails.innerHTML = "";

    const orderHeader = document.createElement("h3");
    orderHeader.textContent = `Order ID: ${order.id}`;

    const orderStatus = document.createElement("p");
    orderStatus.textContent = `Status: ${order.status}`;

    orderDetails.appendChild(orderHeader);
    orderDetails.appendChild(orderStatus);

    modal.style.display = "block";
}

function setupCloseButton() {
    const modal = document.getElementById("orderModal");
    const closeButton = modal.querySelector(".close");

    closeButton.addEventListener("click", () => {
        modal.style.display = "none";
    });
}

function setupConfirmButton(order, token) {
    const modal = document.getElementById("orderModal");
    const confirmButton = modal.querySelector("#confirmOrderBtn");

    if (order.status === "Delivered") {
        confirmButton.style.display = "none";
        return;
    }

    confirmButton.style.display = "block";

    confirmButton.addEventListener("click", () => {
        confirmOrder(order.id, token);
    });
}

function handleError(error) {
    console.error("Error:", error);
}
```

Nah, berdasarkan kode yang diberikan, terdapat beberapa bagian yang belum menerapkan prinsip Clean Code dengan baik. Fungsi fetchOrderDetails() memiliki terlalu banyak tanggung jawab, mulai dari mengambil data dari API, menampilkan informasi pesanan ke modal, mengatur event listener tombol, hingga menangani error. Oleh karena itu,  melakukan beberapa langkah refaktorisasi sebagai berikut.

untuk pertama itu memisahkan proses validasi response dari API ke dalam fungsi validateResponse(). Fungsi ini bertugas memeriksa apakah response berhasil diterima atau tidak. Dengan begitu, fungsi utama menjadi lebih ringkas dan mudah dibaca.

untuk selanjutnya  memisahkan proses menampilkan detail pesanan ke modal ke dalam fungsi displayOrderModal(). Fungsi ini hanya bertanggung jawab untuk membuat dan menampilkan elemen-elemen yang berisi informasi pesanan, sehingga logika tampilan tidak bercampur dengan proses pengambilan data.

Lanjut  membuat fungsi setupCloseButton() untuk mengatur event pada tombol tutup modal. Dengan cara ini, pengelolaan tombol tutup menjadi lebih terorganisir dan dapat digunakan kembali apabila diperlukan.

untuk keempat itu  memisahkan pengaturan tombol konfirmasi ke dalam fungsi setupConfirmButton(). Fungsi ini bertugas memeriksa status pesanan dan menentukan apakah tombol konfirmasi perlu ditampilkan atau disembunyikan. Selain itu, fungsi ini juga mengatur aksi yang akan dijalankan ketika tombol konfirmasi ditekan.

selanjutnya membuat fungsi handleError() untuk menangani error yang terjadi selama proses pengambilan data. Dengan adanya fungsi khusus ini, penanganan error menjadi lebih terpusat dan kode lebih mudah dipelihara.

dan terakhir setelah seluruh proses dipisahkan ke dalam fungsi-fungsi yang lebih kecil, fungsi fetchOrderDetails() hanya berperan sebagai pengatur alur kerja utama. Fungsi ini bertugas memanggil fungsi-fungsi lain secara berurutan sehingga kode menjadi lebih mudah dibaca, dipahami, dan dikembangkan di kemudian hari.

Dengan melakukan refaktorisasi tersebut,seharusnya kode menjadi lebih sesuai dengan prinsip Clean Code karena setiap fungsi memiliki satu tanggung jawab yang jelas (Single Responsibility Principle), penamaan fungsi menjadi lebih deskriptif, serta struktur program menjadi lebih rapi dan mudah untuk dipelihara.
